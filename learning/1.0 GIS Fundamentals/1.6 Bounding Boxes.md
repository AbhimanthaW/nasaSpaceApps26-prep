**Mental Model**
- smallest axis aligned rectangle describing a datasets's spatial extent

raster
- longitude : 100° --> 140°
- latitude : -10° --> + 10°

left   = 100
bottom = -10
right  = 140
top    = 10

```
                  top = 10°
             ┌─────────────────┐
             │                 │
left = 100°  │     raster      │ right = 140°
             │                 │
             └─────────────────┘
                bottom = -10°
```

bounds = spatial extent

**bounds ≠ dimensions**
```
bounds:
x = 0 → 10000 m
y = 0 → 10000 m
```

Raster A:
```
100 × 100
```

Raster B:
```
1000 × 1000
```

same spatial extent. different spatial resolution.

```
Raster A → 100 m/cell
Raster B → 10 m/cell
```

**IMPORTANT**
```
bounds     = where
shape      = how many cells
resolution = spacing/size of cells
```

```
x_resolution = width_in_map_units / number_of_columns
y_resolution = height_in_map_units / number_of_rows
```

**Rasterio window concept**

```python

    left,

    right,
    top,
    transform=src.transform
)
```
