**Practice**
### 1
Two rasters cover exactly the same region.
```
Raster A: 500 × 500
Raster B: 5000 × 5000
```
Assuming both genuinely originate at those sampling scales, which has finer spatial resolution?
Why? 
*Raster B has finer resolution as each pixel represents significantly smaller physical area on the ground*
### 2
Dataset A says:
```
resolution = 100 m/cell
```
Dataset B says:
```
resolution = 1 km/cell
```
Which is called **higher resolution**?
*Dataset A as spatial resolution represents dimensions of a single cell - smaller means surface is sampled at finer intervals*
### 3
A raster has:
```
shape = (4000, 8000)
```
Can you determine spatial resolution from that alone?
Why?
*array dimensions only display number of rows and columns, not spatial extent of the grid which is needed to calculate spatial resolution*
### 4
A Mars raster says:
```
resolution = (0.01°, 0.01°)
```
Can you say each pixel is a constant:
```
X metres × X metres
```
everywhere on Mars?
Explain.
*angular coordinates project onto varying linear ground distances depending on latitude - lines of longitude converge toward poles so cover smaller distance in meters near poles than equator*
### 5
You resample:
```
1000 m/cell
↓
10 m/cell
```
Can you now claim:
> “Our dataset has 10 m scientific resolution.”
Why not?
*resampling (upsampling) increases pixel density via interpolation. effective details reamins bounded by original 1000m physics sensor acquisition limit*

**Applied reasoning**

Two DEMs cover the same Mars region.
```
DEM A:
resolution = 25 m/cell

DEM B:
resolution = 500 m/cell
```
You derive slope from both.
The 25 m DEM shows a steep narrow ridge.
The 500 m DEM shows relatively gentle terrain.

**Explain:**
1. Why can both results be internally correct?
*elevation changes across short baseline distances in DEM A, DEM B smooths out local peaks*

2. Which one would better resolve the narrow ridge?
*DEM A resolves narrow ridge*

3. Why should a rover-routing threshold such as:
```
blocked if slope > 20°
```
not be treated as independent of DEM resolution?
*slope magnitude varies directly with scale so lower resolution might mask treacherous or whatnot*
