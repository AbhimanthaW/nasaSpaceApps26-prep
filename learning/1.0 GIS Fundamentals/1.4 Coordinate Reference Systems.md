**CRS as a Contract**

```
CRS
├── target body
├── datum / reference body
├── coordinate system
├── axis definitions
├── units
├── projection, if projected
└── projection parameters
```

**Geographic CRS**
```
Mars
 ↓ reference body/model
latitude + longitude
```

**Projected CRS**
```
geographic CRS
(lat/lon)
     ↓
projection
     ↓
projected CRS
(x/y)
```

**Geographic vs Projected**

|         Geographic CRS          |                 Projected CRS                  |
| :-----------------------------: | :--------------------------------------------: |
|   Curved planetary reference    |             Flat coordinate plane              |
|         Usually lat/lon         |                  Usually x/y                   |
|          Angular units          |              Usually linear units              |
|             Degrees             |                  Often metres                  |
|    Good for global locations    |     Often useful for regional calculations     |
| Distance calculations need care | Local Euclidean calculations may be meaningful |

```

```
Projection ⊂ projected CRS
```

**CRS Transformation vs Raster Transform**

Raster affine transform
```
(row, col)
↔
(x, y)
```

CRS transformation
```
(x₁, y₁) in CRS A
↔
(x₂, y₂) in CRS B
```

```
ARRAY SPACE
(row, col)
     ↕
raster transform
     ↕
MAP SPACE in CRS A
(x, y)
     ↕
CRS transformation
     ↕
MAP SPACE in CRS B
(x', y')
```

**Debugging challenge**

Three Mars rasters have:

```
Raster A:
CRS = Mars CRS X
shape = (1000, 1000)

Raster B:
CRS = Mars CRS X
shape = (1000, 1000)

Raster C:
CRS = Mars CRS Y
shape = (1000, 1000)
```

A teammate says:

> "A and B have the same CRS and dimensions, so we can definitely combine them cell-by-cell."

Explain why that conclusion is still unsafe.

Then explain why **Raster C** presents an additional problem.

*Raster A and B's affine transforms and resolutions might differ. *same CRS + same shape ≠ same grid*
*raster C has a different CRS than A and B so it must be reprojected to CRS X before cell-by-cell operations can occur*
